## 🧠 Sobre mim

Sou um desenvolvedor apaixonado por tecnologia e inovação.  
Gosto de aprender constantemente e criar soluções que resolvam problemas reais.

Atualmente estou cursando **Ciência da Computação** e desenvolvendo projetos envolvendo:

- APIs e sistemas web
- aplicações com **Django**
- backend com **.NET C#**
- bancos de dados **SQL**
- infraestrutura de redes

Também tenho experiência prática com **infraestrutura de TI**, incluindo configuração de **redes, switches, modems e CFTV**.
